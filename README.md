เกม HTML Canvas / JavaScript ไม่ต้องติดตั้ง dependencies

## เล่น
เปิด dist/index.html หรือเสิร์ฟโฟลเดอร์ dist ด้วย static web server

## Cloudflare Pages
สร้าง Pages project แบบ Direct Upload แล้วอัปโหลดไฟล์ใน dist (หรือ ZIP ดาวน์โหลดจากหน้าเกม) โดยให้ index.html อยู่ชั้นบนสุด ไม่ต้อง build และไม่ต้องมี API key ในโค้ด

## ระบบ
6 สถานี, 10 เวฟ, บอสเวฟ 5/10, 6 หัวหน้ากะ, อัปเกรดพลังและความเร็ว, โบนัสหลังเวฟ, เสียง, หยุด/เร่งเวลา, สถิติสูงสุด localStorage
ใช้ภาพฉาก สถานี ออร์เดอร์ และหัวหน้ากะที่ผู้ใช้ส่งมา; ถุงส่งสำเร็จวาดด้วย Canvas
สถิติเก็บในเครื่องเท่านั้น ไม่มี leaderboard กลางหรือ login

## รุ่น 04 — เต็มจอแนวนอน + เพลง
แผนที่ใช้พื้นที่หน้าจอทั้งหมด รักษาสัดส่วนภาพ มี HUD ด้านบนและ dock สถานีด้านล่าง ไม่มีหน้าเว็บเลื่อนยาว จุดวางมีพื้นที่แตะขั้นต่ำเส้นผ่านศูนย์กลาง 56 CSS px เลือกจุดที่ใกล้ที่สุด หน้าต่างอัปเกรดปิดได้
มือถือแนวตั้งพัก simulation และแสดงหน้าหมุนจอ ปุ่ม ⛶ ขอ fullscreen และ lock landscape เมื่อ browser รองรับ หากไม่รองรับให้หมุนเครื่องเอง
ปุ่ม ♫: เลือกเสียงร้อง/บรรเลง/ปิดทั้งหมด; ปิดทั้งหมดหยุดทั้งเพลงและเอฟเฟกต์ มีระดับเสียงและพักเพลง เพิ่มไฟล์เครื่อง (เฉพาะ session ไม่อัปโหลด) หรือ HTTPS direct audio URL ซึ่งจำไว้ใน localStorage ของเครื่องนั้น
ยังไม่มีเพลงของร้านแนบในรุ่นนี้ หากต้องการ playlist สำหรับทุกคน ใส่รายการใน dist/music.json เช่น [{"name":"ชื่อเพลง","kind":"vocal","url":"https://YOUR-PUBLIC-AUDIO-URL/song.mp3"}] ใช้ kind instrumental สำหรับบรรเลง รองรับ public Supabase Storage audio URLs โดยไม่ต้องใส่ API key; private bucket ต้องมี signed URL ที่ยังไม่หมดอายุ
ตรวจ engine / evolution และ mock playback controls ผ่าน; ตรวจ UI desktop กับ iframe ขนาด 844x390 และ390x844 แล้ว ยังไม่ทดสอบอุปกรณ์ Android จริงหรือไฟล์เพลง Supabase ของร้าน
