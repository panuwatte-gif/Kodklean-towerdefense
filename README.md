# กะเพราโคตรคลีน — ครัวแตก!
เกม HTML Canvas / JavaScript ไม่ต้องติดตั้ง dependencies

## เล่น
เปิด dist/index.html หรือเสิร์ฟโฟลเดอร์ dist ด้วย static web server

## Cloudflare Pages
สร้าง Pages project แบบ Direct Upload แล้วอัปโหลดไฟล์ใน dist (หรือ ZIP ดาวน์โหลดจากหน้าเกม) โดยให้ index.html อยู่ชั้นบนสุด ไม่ต้อง build และไม่ต้องมี API key ในโค้ด

## ระบบ
6 สถานี, 10 เวฟ, บอสเวฟ 5/10, 6 หัวหน้ากะ, อัปเกรดพลังและความเร็ว, โบนัสหลังเวฟ, เสียง, หยุด/เร่งเวลา, สถิติสูงสุด localStorage
ใช้ภาพฉาก สถานี ออร์เดอร์ และหัวหน้ากะที่ผู้ใช้ส่งมา; ถุงส่งสำเร็จวาดด้วย Canvas
สถิติเก็บในเครื่องเท่านั้น ไม่มี leaderboard กลางหรือ login
